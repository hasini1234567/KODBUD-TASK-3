Introduction

The Indian Premier League (IPL) is one of the most popular cricket tournaments in the world. Large amounts of data are generated during each season, including match results, player performances, and venue statistics. This project focuses on analyzing IPL data to identify winning teams, top-performing players, and stadium trends using Exploratory Data Analysis (EDA) techniques.

Objective

The main objectives of this project are:

* Analyze IPL match results across seasons.
* Identify the most successful teams.
* Study top scorer trends.
* Analyze stadium usage patterns.
* Compare team performances.
* Visualize IPL statistics using charts and graphs.
* Learn data cleaning, analysis, and visualization techniques.

Dataset Description

The dataset contains IPL information with the following attributes:

* Season
* Winner Team
* Top Scorer
* Stadium

Exploratory Data Analysis

6.1 Most Winning Teams Analysis

The winning teams were analyzed to identify the most successful IPL franchises.

Observation:

* CSK appeared as the most successful team.
* MI also showed strong performance.
* Other teams won fewer matches.

6.2 Top Scorers Analysis

Top scorers were analyzed to understand player performance trends.

Observation:

* Shubman Gill appeared multiple times.
* Different seasons had different top-performing batsmen.
* Top scorers contributed significantly to team success.

6.3 Stadium Analysis

Stadium data was analyzed to study venue usage trends.

Observation:

* Chennai and Mumbai hosted multiple matches.
* Some stadiums hosted fewer matches.
* Venue analysis helps understand match distribution.

6.4 Team Performance Analysis

Team performance was compared based on match wins.

Observation:

* CSK achieved the highest number of wins.
* MI followed closely behind.
* Team consistency played a major role in success.

6.5 Player Performance Analysis

Player appearances as top scorers were examined.

 Observation:

* Shubman Gill appeared more frequently than other players.
* Consistent player performance impacts team outcomes.
* Emerging players showed strong contributions.

6.6 Trend Analysis

Overall IPL trends were studied across seasons.

Observation:

* Team performance varied from season to season.
* New teams emerged as strong competitors.
* Player performances influenced tournament results.
